# Saboot: binding Hindi news numbers to official statistics

Saboot is a small dataset and binding study of numerical claims about Indian central government schemes in Hindi news. For each claim it records whether a dated official figure exists for the same metric, geography and period, and whether the numbers agree.

It was made for the Apart Research AI x Epistemics Research Sprint (November 2026). Everything in this repository (code, data, labels, verifier run and paper) was written during the sprint, 13 to 15 November 2026; there is no preexisting code. The paper is `report/saboot-final-v2.pdf` (on the official Apart template; source `report/saboot-final-v2.docx`, built from `report/saboot-final-v2.md`). It adds the evidence-given condition; the first submitted version, `report/saboot-final.pdf`, is kept for the record.

## What is in it

- **102 claims** from 37 articles in four Hindi outlets (Prabhat Khabar, Aaj Tak, Patrika, Amar Ujala), published 2 August to 11 November 2026, about six schemes: PM-KISAN, PM-JAY, Jal Jeevan Mission, PMAY, MGNREGA and PM Ujjwala.
- **A label for every claim:** bound + match, bound + mismatch, bound-ambiguous or unbindable, with the official URL, as-of date, official value, a verbatim evidence quote and a one-line reason.
- **A verification record** for each of the 46 bound or ambiguous claims: the official page was opened in a browser and the figure, date and scope were compared with the record.

Main results (from `report/tables.md`):

| Measure | Result |
|---|---|
| Coverage (any binding) | 45.1% (46/102, 95% CI 35.8-54.8%) |
| Strict coverage (same metric, geography, period) | 24.5% (25/102) |
| Coverage, India-level claims | 69.2% (36/52) |
| Coverage, state-level claims | 20.0% (10/50) |
| Match rate among cleanly bound claims, strict | 88.0% (22/25) |
| Match rate among cleanly bound claims, within 5% | 92.0% (23/25) |

## Reproduce the tables

Python 3.10 or later, standard library only.

```bash
python -I scripts/label.py               # labels from claims + binding decisions -> data/bindings.jsonl
python -I scripts/merge_verification.py  # applies the browser check -> data/bindings_verified.jsonl
python -I scripts/report_tables.py       # every number and figure -> report/tables.md, report/figures/
python -I -X utf8 scripts/score_verifier.py   # verifier scores -> report/verifier_tables.md, figure 2
python -I -X utf8 scripts/score_evidence.py   # evidence-given scores -> report/evidence_tables.md
python -I -X utf8 scripts/build_paper_docx.py report/saboot-final-v2.md # paper on the Apart template -> report/saboot-final-v2.docx
```

`report_tables.py` renders a PNG copy of the figure with a local Edge or Chrome if one is installed. Two checks need the raw pages that are not released: `scripts/build_claims.py` (each claim clause appears verbatim in its article) and the evidence-quote check in `report_tables.py` (each quote appears in the saved official page text). Without `data/raw/`, `report_tables.py` says the quote check was not run; every other number is the same. To rebuild from scratch, fetch the URLs in `data/article_urls.txt` with `scripts/extract.py` (polite, cached, robots.txt respected).

## Verifier evaluation

`scripts/run_verifier.py` asked gemini-3.5-flash-lite (Gemini API free tier, temperature 0, closed-book: scheme, claim and article date only) to check all 102 claims, once with the Hindi clause and once with the English gloss, on 14 November 2026. gemini-3.8-flash was overloaded (HTTP 503) and answered one call, so it is excluded; the planned gemini-2.5 models were not available to new keys. Main results (from `report/verifier_tables.md`):

| Measure | Result |
|---|---|
| "Cannot verify" on unbindable claims | 93.8% (105/112 answers) |
| "Cannot verify" on cleanly bound claims | 92.0% (46/50) |
| Verdict agreement with the labels | 71.6% (146/204); always "cannot verify" scores 75.5% |
| Committed answers that were right | 4/16 |
| Cited sources that showed the stated figure | 0/16; all 7 cited PIB release IDs open unrelated releases |
| Same verdict for Hindi and English wording | 90.2% (92/102) |

## Evidence-given evaluation

`scripts/build_evidence_excerpts.py` built one official excerpt per claim by fixed rules: windows around the verified quote for the 46 bound or ambiguous claims, and a near-miss excerpt (same scheme, but not the claim's figure) for 55 unbindable claims; one unbindable claim (C057) had no usable page. Every excerpt is frozen in `data/evidence_excerpts.jsonl` with a SHA-256 hash, and `scripts/run_evidence.py` refuses any excerpt whose hash has changed. The same model then labelled each claim MATCH, MISMATCH, AMBIGUOUS or CANNOT_VERIFY, in Hindi and English (202 calls, 14 November 2026). Scored by `scripts/score_evidence.py` (`report/evidence_tables.md`):

| Measure | Result |
|---|---|
| False abstention on cleanly bound claims | 0.0% (0/50), down from 92.0% closed-book |
| Answers on matching claims labelled MATCH | 97.7% (43/44) |
| Ambiguous claims labelled AMBIGUOUS | 0/42 answers |
| Near-miss answers: CANNOT_VERIFY / MISMATCH / MATCH | 83.6% / 13.6% / 1.8% (of 110) |
| Four-label agreement | 68.8% (139/202); the excerpt-type baseline scores 76.2% |
| Same label for Hindi and English wording | 89.1% (90/101) |

## Limits

- Labels follow the fixed rules in `data/labelling-rules.md`. Every official page behind a binding was re-opened in a browser, and every cited official figure was checked against the saved official page text by script. One annotator, so no inter-annotator agreement is reported.
- 102 claims, four outlets, three and a half months: not representative of all Hindi media. PM Ujjwala (4) and MGNREGA (9) have few claims.
- "Unbindable" means no figure was found in the listed central sources (PIB, scheme dashboards and archives, Parliament answers). It does not mean the claim is false. State-government releases and data.gov.in were not searched.
- Binding checks agreement with official figures, not truth. A mismatch is a measurement outcome under stated rules, not an accusation against any outlet or speaker.
